## 화면 구성

### 페이지

1. 로그인 페이지

- ID, PW 입력 (고객 관리자 이메일을 ID로 사용)
- 로그인 시 IP 또는 MAC 어드레스 체크도 함께 포함
- 로그인 성공 시 메인 페이지로 이동

2. 메인 페이지 (데시 보드)

- 회사 정보 및 등록된 모터 정보 표시
- 간단한 현황 정보 표시 : 서비스 시작 일자, 총 일 수, NORMAL 제외 한 상태 별 수 등
- 등록된 모터 별 모터 이미지 --> API 이미지 --> AI Agent
  . 모터 아래 현재 상태 정보 표시 (예 : WARNING + 일시)
  . 상태 정보 표시 시 단계별 색깔 구분 (NORMAL, WARNING, DANGER, FAULT)
  . '-->' 데이터가 흐르는 것 처럼 보이도록 함. gif로 움직임을 표시 (애니메이션 효과)

```
모터1 이미지 --> API 이미지 --> AI Agent
(모터 모델명 
NORMAL
26/07/01 13:05)

모터2 이미지 --> 
(모터 모델명 
WARNING
26/07/01 13:05)

모터3 이미지 --> 
(모터 모델명 
NORMAL
26/07/01 13:05)
```

- 이벤트 발생 내역 리스트
  . 발생 일시, 모터명, 모터 상태, 리포트가 있을 경우 다운로드 버튼
  . 최근 최대 10개 표시

3. 머터 상세 페이지

- 메인 페이지에서 머터를 클릭 시 머터 상세 페이지로 이동
- 머터에 대한 세상 정보 표시
  . 등록일자, 머터명, 모델명, 위치 정보, 시리얼 번호
  . 모터 신호에 대한 각 항목별 범위 값
  (예) 온도 : NORMAL (??? ~ ???), WARNING (??? ~ ???), DANGER (??? ~ ???), FAULT (??? ~ ???))
- 이벤트 발생 내역 리스트
  . 발생 일시, 모터명, 모터 상태, 리포트가 있을 경우 다운로드 버튼
  . 페이징, 페이지 당 20개씩 표시


| **라이브러리**     | **Rendering 엔진**              | **초기 렌더링 속도** | **데이터 용량 한계 (쾌적한 60 FPS 기준)**        | **인터랙션 / 애니메이션 성능**                         |
| ------------------------ | ------------------------------------- | -------------------------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| **D3.js**          | **SVG / Canvas**(선택)          | 보통 ~ 느림                | SVG: ~2,000개Canvas:**50,000개+**                | 직접 최적화(DOM 조작 최소화) 시 최고의 퍼포먼스              |
| **Chart.js**       | **Canvas**                      | **빠름**             | **~10,000개 ~ 20,000개**                         | 대량 데이터 연산 시 훌륭함, 차트 전체를 다시 그리는 구조     |
| **Recharts**       | **SVG**(React DOM)              | 보통                       | **~1,000개 미만**                                | 데이터 1,000개 이상부터 React 가상 DOM 비교로 지연 발생      |
| **Apache ECharts** | **Canvas / SVG / WebGL**        | **매우 빠름**        | Canvas:**50,000개+**WebGL:**1,000,000개+** | 데이터 다운샘플링, Progressive Rendering 등 최적화 무기 다수 |
| **Visx**           | **SVG**(React Canvas 연동 가능) | 빠름 (D3보다 가벼움)       | **~2,000개 내외**                                | React 불필요한 리렌더링 최소화 구조로 Recharts보다 약간 빠름 |
