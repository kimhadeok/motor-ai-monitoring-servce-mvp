### 테이블 설계

```
컬럼명,데이터 타입,제약조건,설명

1. companies (업체 정보 테이블)
   company_id,VARCHAR(50),PK,업체 코드 (예: COMP-001)
   company_name,VARCHAR(100),NOT NULL,업체명 (예: (주)한국모터스)
   created_at,TIMESTAMPTZ,NOT NULL,등록일시

2. company_contacts (담당자 연락처 테이블)
   contact_id,BIGSERIAL,PK,담당자 고유 ID
   company_id,VARCHAR(50),FK,업체 코드 (companies.company_id 참조)
   contact_name,VARCHAR(50),NOT NULL,담당자 이름
   phone_number,VARCHAR(20),NOT NULL,담당자 전화번호
   email,VARCHAR(100),UNIQUE, NOT NULL,로그인 ID로 사용할 이메일 주소
   password_hash,VARCHAR(255),NOT NULL,보안을 위해 암호화(해시)된 비밀번호
   is_primary,BOOLEAN,DEFAULT FALSE,대표 담당자 여부
   allowed_ip,VARCHAR(100),NULL,[보안 강화용] 접속 허용 IP (값이 있으면 해당 IP만 로그인 허용)
   created_at,TIMESTAMPTZ,NOT NULL,등록일시

3. motors (모터 장비 정보 테이블)
   motor_id,VARCHAR(50),PK,모터 고유 식별자 (예: MTR-001)
   company_id,VARCHAR(50),FK,업체 코드 (companies.company_id 참조)
   motor_name,VARCHAR(100),NOT NULL,모터 이름 (예: 2호기 메인 송풍기)
   installation_location,VARCHAR(150),NOT NULL,설치 위치 (예: 제1공장 지하 1층 기계실)
   model_name,VARCHAR(100),NOT NULL,모터 모델명 (예: HYUN-37KW-4P)
   serial_number,VARCHAR(100),UNIQUE,제조사 시리얼 번호 (예: SN-2026-98765)
   normal_range,FLOAT,NULL,정상 시작 값 (예: normal_range <= 값 < warning_range)
   warning_range,FLOAT,NULL,경고 시작 값 (예: warning_range <= 값 < danger_range)
   danger_range,FLOAT,NULL,위험 시작 값 (예: danger_range <= 값 < fault_range)
   fault_range,FLOAT,NULL,고장/오류 판단 임계값 (예: 값 >= fault_range)
   created_at,TIMESTAMPTZ,NOT NULL,등록일시

4. motor_telemetry (실시간 센서 데이터 및 항목별 상태 - 시계열)
   time,TIMESTAMPTZ,PK (Hypertable),데이터 수집 시점
   motor_id,VARCHAR(50),PK,모터 고유 식별자 (motors.motor_id 참조)
   company_id,VARCHAR(50),FK,업체 코드 (companies.company_id 참조)
   temperature,FLOAT,NOT NULL,온도 값 (℃)
   temp_status,VARCHAR(20),NOT NULL,온도 상태 (NORMAL, WARNING, DANGER, FAULT)
   vibration,FLOAT,NOT NULL,진동 값 (mm/s)
   vib_status,VARCHAR(20),NOT NULL,진동 상태
   current,FLOAT,NOT NULL,전류 값 (A)
   current_status,VARCHAR(20),NOT NULL,전류 상태
   sound,FLOAT,NOT NULL,소음 값 (dB 등)
   sound_status,VARCHAR(20),NOT NULL,소음 상태

5. motor_status_logs (상태 변화 및 AI 에이전트 이벤트 로그)
   log_id,BIGSERIAL,PK,로그 고유 번호
   motor_id,VARCHAR(50),FK,모터 고유 식별자 (motors.motor_id 참조)
   metric_name,VARCHAR(50),NOT NULL,대상 지표명 (temperature, vibration, current, sound)
   previous_status,VARCHAR(20),NOT NULL,이전 상태
   new_status,VARCHAR(20),NOT NULL,변경된 상태
   trigger_reason,TEXT,NULL,상태 변화 원인 (예: 진동 임계치 초과)
   agent_diagnosis,VARCHAR(255),NULL,AI 에이전트가 생성한 PDF 보고서 파일의 URL 링크 정보
   created_at,TIMESTAMPTZ,NOT NULL,상태 전환 시점 (쿨다운 계산 기준)

6. login_logs (로그인 이력 테이블)
   log_id,BIGSERIAL,PK,로그 고유 번호 (Auto Increment)
   contact_id,BIGINT,FK (Null 허용),로그인 시도한 담당자 ID (company_contacts.contact_id 참조)
   ip_address,VARCHAR(45),NOT NULL,로그인을 시도한 클라이언트 IP 주소
   created_at,TIMESTAMPTZ,NOT NULL,로그인 시도 시점

7. notification_logs (알림 및 이메일 발송 이력 테이블)
   notification_id,BIGSERIAL,PK,알림 이력 고유 번호
   motor_id,VARCHAR(50),FK,대상 모터 ID (motors.motor_id 참조)
   contact_id,BIGINT,FK,수신한 담당자 ID (company_contacts.contact_id 참조)
   channel_type,VARCHAR(20),NOT NULL,발송 채널 (KAKAO_ALIMTALK, SMS, EMAIL)
   external_message_id,VARCHAR(100),NULL,API 제공 업체에서 전달받은 발송 레퍼런스 ID (Message ID)
   title,VARCHAR(200),NULL,제목 또는 알림 요약
   message_content,TEXT,NOT NULL,실제 발송된 메시지 내용
   created_at,TIMESTAMPTZ,NOT NULL,알림 발송 시도 시점
```
